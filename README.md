## End to End Machine Learning Project

Problem Statement - To understand the student's performance (test scores) which can be affected based upon other variables such as Genders, Type of Lunch, Parental level of education, and the type of test preparation that they have worked on to achieve the scores.

Life Cycle of this project - 
Figuring out the problem statement -> Data Collections -> Data Cleaning -> EDA -> Data Pre-processing -> Model Training -> Choosing the best models out.
